# Media uploads

Upload images and videos into this folder (any file names). They are then wired into the
slots below, replacing the stand-in photos currently used.

## Recommended formats

| Type | Format | Size |
|---|---|---|
| Header slider images | JPG or WebP | 2400 × 1350 px, under 500 KB each |
| Video backdrops | MP4 (H.264), no sound, 10–20 s seamless loop | 1920 × 1080 (or 1280 × 720), under 8 MB each |
| Parallax break images | JPG or WebP | 2400 × 1350 px, under 500 KB |
| Service and audience images | JPG or WebP | 1600 × 1200 px (4:3) |

Darker, uncluttered footage works best behind text; the site adds a navy overlay on top.
